# Динамическое программирование
Алгоритмы из темы "Динамическое програмирование", разобранные на практике
## Структура проекта
В header-файлах (.h) реализации алгоритмов, в main.cpp Demo-функции, которые можно попробовать вызвать со своими входными данными
## Сборка и запуск
Либо через Cmake
```
cmake .
cmake --build build
// Далее запускаете исполняемый файл Dynamic_programming в папке build
```
Либо напрямую
```
// macos:
g++ main.cpp && ./a.out
// windows:
g++ main.cpp && .\a.exe
```
(Вместо g++ имя вашего компилятора)
